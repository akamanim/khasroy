# Хасрой v0.1

Рабочий локальный прототип персонального AI-ассистента: React 19, TypeScript, Tailwind CSS 4, Next.js-совместимый App Router через Vinext/Vite.

## Запуск

Требуется Node.js 22.13+ и npm.

```sh
npm run install:ci
npm run dev
```

Откройте локальный адрес, указанный в терминале (обычно http://localhost:5173).

```sh
npm run build
npx tsc --noEmit
```

## Что работает

- Анимированная сфера из 2600 частиц на Canvas с трёхмерной проекцией и орбитами, без внешних изображений.
- Изменение свечения при фокусе на чате и ускорение движения при обработке сообщения.
- История текущего диалога, отправка кнопкой или Enter, Shift+Enter для новой строки, новый диалог, готовые подсказки.
- Адаптивный интерфейс и поддержка системного предпочтения уменьшенной анимации.

Чат демонстрационный. Ответы выбираются локально; никакая AI-модель, серверная память или самообучение не подключены. Перезагрузка страницы очищает диалог. Индикатор ONLINE означает готовность интерфейса, а не подключение к AI.

## Подключение AI

`lib/chat.ts` — единая точка подключения. Замените тело функции `chat(messages)` на запрос к своему серверному POST /api/chat. Контракт: история `{id, role, content}[]`, результат — текст ответа. Сервер должен хранить API-ключ, проверять размер и роли сообщений и возвращать понятные ошибки. Не добавляйте API-ключ в клиентский код. UI уже обрабатывает ожидание и ошибку запроса.

`components/khasroy/core.tsx` — независимое визуальное ядро; `app/page.tsx` — чат и состояние; `app/globals.css` — тема и адаптивность.

## Размещение

Этот прототип запускается локально. Имя пакета — `khasroy-ai`, отображаемое имя — «Хасрой». Starter использует Vinext и Cloudflare-совместимую сборку; для Vercel потребуется адаптация к обычному Next.js или отдельное размещение frontend/backend.
