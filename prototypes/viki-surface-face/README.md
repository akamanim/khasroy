# Khasroy — Surface Face Projection Lab

Отдельный визуальный прототип. Production Khasroy не затрагивает.

## Что уже реализовано
- 3D-сфера с полупрозрачной энергетической оболочкой.
- Частицы на поверхности.
- Три переплетённые энергетические ленты вокруг ядра.
- Женские черты лица проецируются прямо на переднюю поверхность сферы.
- Яркие глаза, линии носа, скул, подбородка и губ.
- Фейковая анимация речи губ.
- Автоматический цикл: `IDLE → FORMING → SPEAKING → DISSOLVE`.
- Лёгкое живое движение и реакция на движение указателя.
- Адаптация количества частиц для мобильного экрана.
